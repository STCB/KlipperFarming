# Pi Zero + USB Ethernet Case

Solidworks and STL files, ready to 3D print.

This case was adapted from a [Thingiverse design](https://www.thingiverse.com/thing:1161310), to make the Pi fit an [Ethernet + USB to microUSB hub](https://amzn.eu/d/08qYqluK)

The USB hub provides both RJ45 ethernet connexion to the Pi, and printer access through USB cables.
