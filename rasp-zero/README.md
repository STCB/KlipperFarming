# Raspberry Pi Zero (bridge)

Purpose: expose the printer's USB serial over TCP using ser2net.

## Setup outline
1. Install Raspberry Pi OS Lite.
2. Connect printer(s) to the Pi Zero USB hub + Ethernet setup.
3. Install ser2net: `sudo apt-get install -y ser2net`.
4. Keep one canonical config file at `/etc/ser2net.yaml`.
5. Ensure `/etc/default/ser2net` points to that file:
   - `CONFFILE="/etc/ser2net.yaml"`
6. Enable SSH key access from the server orchestrator user.
7. Restart: `sudo systemctl restart ser2net`.

## Notes
- This is tested on Raspbian GNU/Linux 13 (trixie) with ser2net 4.6.x (YAML config).
- The packaged systemd unit runs `/usr/sbin/ser2net -n -c /etc/ser2net.yaml`.
- Debian-style installs may also create `/etc/ser2net/ser2net.yaml`; keep it removed to avoid ambiguity.
- In farm mode, `/etc/ser2net.yaml` is generated by the server reconciler from live USB discovery.
- Identity preference is `by-id`, then `by-path`, then direct tty fallback.
- Default baud is `250000` (Klipper default).
